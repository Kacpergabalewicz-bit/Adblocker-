📦 INSTALACJA (Chrome / Edge)
1) Pobierz ZIP z linku powyżej (sekcja Assets)
2) Rozpakuj folder na komputerze
3) Otwórz: chrome://extensions/ (lub edge://extensions/)
4) Włącz: Tryb dewelopera
5) Kliknij: Załaduj rozpakowane
6) Wybierz folder rozszerzenia

✅ Po instalacji przypnij ikonę rozszerzenia obok paska adresu.

🚀 SZYBKI START
1) Wejdź na dowolną stronę
2) Kliknij ikonę rozszerzenia
3) Włącz przełącznik „Status ochrony” (ON)
4) Gotowe — blokowanie działa

🧩 FUNKCJE + JAK ICH UŻYWAĆ

1) Globalne ON/OFF
- Gdzie: Popup (ikona rozszerzenia)
- Jak: przełącznik „Status ochrony”
- Efekt: włącza/wyłącza całe rozszerzenie

2) Biała lista dla aktualnej strony
- Gdzie: Popup
- Jak: przełącznik „Biała lista dla tej strony”
- Efekt: dla tej domeny blokowanie jest wyłączone

3) Pauza tylko dla tej karty
- Gdzie: Popup
- Jak: przełącznik „Pauza tylko na tej karcie”
- Efekt: blokowanie jest pauzowane tylko na aktualnej karcie, inne działają normalnie

4) Liczniki blokad
- Gdzie: Popup
- Co pokazuje:
	- „Na tej karcie” = blokady na bieżącej karcie
	- „Łącznie” = wszystkie blokady od uruchomienia
	- „Najczęściej blokowana domena” = top domena z licznika

5) Własne domeny do blokowania
- Gdzie: Ustawienia rozszerzenia
- Jak wejść: ikona rozszerzenia -> „Ustawienia filtrów”
- Jak dodać: wpisz np. ads.example.com -> „Dodaj”

6) Własna biała lista domen
- Gdzie: Ustawienia rozszerzenia
- Jak dodać: wpisz domenę (np. example.com) -> „Dodaj”
- Efekt: ta domena będzie pomijana przez blokowanie

7) Import list domen (NOWE)
- Gdzie: Ustawienia -> „Import domen z tekstu / pliku”
- Jak:
	- wklej listę domen/reguł i kliknij „Importuj do blokad”,
	- albo wybierz plik txt/list i potem kliknij import
- Obsługa: zwykłe domeny + reguły typu ||example.com^

8) Źródła list + auto‑update (NOWE)
- Gdzie: Ustawienia -> „Źródła list (auto‑update)”
- Jak:
	- dodaj URL listy (np. https://.../adlist.txt),
	- kliknij „Synchronizuj teraz”,
	- opcjonalnie włącz „Auto‑aktualizacja źródeł (co ~3h)”

9) Top 5 najczęściej blokowanych domen (NOWE)
- Gdzie: Ustawienia -> „Top 5 najczęściej blokowanych domen”
- Efekt: pokazuje które domeny były najczęściej blokowane

10) Ukrywanie elementów reklamowych (cosmetic filtering)
- Gdzie: Ustawienia
- Jak: przełącznik „Ukrywanie elementów reklamowych”
- Efekt: usuwa widoczne boksy reklamowe na stronach

11) Reset licznika
- Gdzie: Ustawienia
- Jak: przycisk „Resetuj licznik”

⚙️ JAK WEJŚĆ W USTAWIENIA

Opcja 2: chrome://extensions -> szczegóły rozszerzenia -> Opcje
